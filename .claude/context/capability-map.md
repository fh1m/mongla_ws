# Capability Map

**The map lives at [`docs/capability-map.md`](../../docs/capability-map.md)**, published at
<https://fh1m.github.io/duburi_ws/capability-map.html>.

Every capability of the srot + Pi/Hailo platform, beside what the Pixhawk + Jetson stack
could do, with a file or a measurement as evidence for each row and one of four states:
WATER, BENCH, BUILT or BLOCKED. Nothing is WATER yet — this platform has not been in water.
Section 7 is the blocked list, with what unblocks each item.

Numbers referenced there are maintained in [`measured-bars.md`](measured-bars.md), which is
read by tests, so a documented number cannot drift away from the code.
