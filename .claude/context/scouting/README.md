# RoboSub Team Intelligence — Mongla Vision Roadmap

This folder tracks competitive intelligence from top RoboSub teams, organized
as actionable insights for the Mongla / Duburi AUV vision and autonomy stack.

## Files

| File | Team | Year | Focus |
|------|------|------|-------|
| [bumblebee-2025.md](bumblebee-2025.md) | Bumblebee (NUS Singapore) | RoboSub 2025 **1st place** | XFeat pose estimation, DepthAnything, HDBSCAN clustering, UKF fusion |

## How to use this folder

1. After each competition season, add a new file: `<teamname>-<year>.md`
2. Extract **transferable techniques** — not just what they did, but WHY it beats our current approach
3. Map each insight to a planned Mongla implementation in the "Adoption Plan" section of each file
4. Update `ROADMAP.md` with prioritized items

## Adoption priority guide

- **P0 — Pre-pool-day**: Implement before any pool testing session
- **P1 — Competition day**: Implement before the competition run
- **P2 — Post-competition**: Nice-to-have, deferred after the event
- **Research only**: Understanding the concept; no immediate code planned
